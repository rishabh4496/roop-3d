## Camera conversion (task 2)

* `PerspectiveCamera` (`reconstruction/geometry_types.py`): full 3x3 K (`CameraIntrinsics`) + SE(3) `[R|t]`, true perspective divide, camera-space Z depth (positive, smaller = closer), `view_cosine`, `head_pose()` -> `full_head.HeadPose`, `from_scaled_pose(...)` (places the camera at Z0 = fx / scale). Consumers moved: `multiview_fit` (`ViewFit.camera`, `camera_for`, `ViewPoseFit.camera`), `uv_synthesizer` (visibility via per-point view cosine and perspective Z-buffer; GPU path passes a real `HeadPose` instead of the old `OrthographicPose` shim), `tracking/lighting`, `scene_adaptation`, `video_tracker`, `rendering/vertex_raster.perspective_pixels`.
* `core.pose.estimate_pose_5pt` is now EPnP + iterative PnP (size-free nominal 0.6 m camera) instead of a 2x3 scaled-orthographic least squares; `project_model5` is a pin-hole projection.
* `GPUHeadRasterizer.render_buffers` rejects an orthographic/affine pose and validates K/R/t with the guard; the affine branch of its clip-space math is gone. `rendering/cpu_perspective_raster.rasterize` rejects `perspective=False`.

## UV-only detailer (task 3)

`enhancers/uv_detailer.py::UVTextureDetailer(session | runner)`: tile-wise neural detail for a square **1024/2048 canonical UV albedo** atlas (Hann-blended 512 tiles, Laplacian fusion so low frequencies stay the measured atlas, valid-mask aware); normal maps get a measured luminance high-pass only (no network). Any other size (frames, aligned crops, 512 portraits) raises `UVDetailerInputError`. ## Guard API (task 5): `app/roop_3d/core/true3d_guard.py`, exported from `roop_3d.core`

* `True3DArchitectureGuard(policy=GuardPolicy())`: `inspect_head_mesh` (no raise), `validate_head_mesh`, `validate_camera`, `validate_render_config`, `assert_true_3d(mesh=..., camera=..., config=...)`, `describe()`; module-level functions of the same names.
* `validate_head_mesh(V, F, regions=None, parts=None, face_direction=(0,0,-1), up_direction=(0,-1,0), require_parts=True, require_watertight=True)`: V (N,3) finite, >= 1500 vertices, F int triangles, no orphan vertices; **watertight = every undirected edge in exactly 2 faces with consistent winding** (reports boundary / non-manifold / mis-wound counts); solid-head extents (planarity, depth/height, >= 18 % of vertices behind the depth centre, >= 13/16 normal-azimuth sectors, crown and chin-underside normals); regions cranium / forehead_dome / temples / cheekbones / mandible / submental_neck (explicit FLAME/MakeHuman vertex-group labels via `regions=`, else geometric inference) each with a minimum vertex count; eyeball spheres (two, radius 7-20 mm, spherical, plausible spacing) and oral cavity (teeth + tongue or an explicit part) when `require_parts`. A frontal landmark strip fails on size, planarity, depth, back-of-head, regions. `close_open_boundaries(V, F)` caps neck/mouth/socket loops (the real MakeHuman head, 4481 verts, has 434 open edges and passes every other check once capped, frame `face_direction=(0,0,1)`).
* `validate_camera(K, R, t, vertices=None, mesh_z_toward_viewer=False, image_size=None, projection_matrix=None)`: finite 3x3 K with bottom row (0,0,1), `K[1,0]=0`, fx,fy > 0, plausible aspect, |skew| <= 1e-3 fx, principal point inside the image; 2x3 / affine rows and an affine 3x4 P are rejected (`AffineCameraError`); R orthonormal det +1, finite t, positive Z for all vertices.
* `validate_render_config(cfg)`: `projection == "perspective"`, Z-buffered rasterizer, shader PBR + subsurface scattering **or** 3D Gaussian; rejects affine / orthographic / weak_perspective / screen_space / 2d / 2.5d values and swapper / restorer / crop-paste / pose-blend keys.
* Exceptions (all `DomainError`): `True3DArchitectureError` > `HeadMeshError` (> `NotWatertightError`, `IncompleteHeadTopologyError`), `CameraModelError` (> `AffineCameraError`, `CameraPoseError`), `RenderConfigError`, `True3DRendererUnavailable` (503). Helpers: `require_true3d_renderer(what)`, `renderer_is_wired()`, `intrinsics_from_fov`, `solve_dynamic_intrinsics(landmarks, width=, height=)` (wraps the existing `reconstruction.dynamic_camera` focal-length solver and validates the result; no new solver was needed).
* Wired into: `ReferencePipeline.infer_frame`, `make_stream_runner`, `EndToEndVideoJobRunner.run_prepared`, `MasterPipelineRunner.prepare` (pass export), `EngineRegistry`, `GPUHeadRasterizer.render_buffers` (perspective + K/R/t), `FullHeadEngine.process` (`validate_architecture()` on the capped rig mesh), `rendering.cpu_perspective_raster.rasterize`, `models.engine_readiness`.

## What remains (honest list)

Remaining banned/borderline items and why:

1. **Scaled-orthographic solver still inside the identity fit.** `multiview_fit` (MAP bundle adjustment residual model `s*(R X)_xy + t`, `solve_view_pose`, `estimate_pose_from_landmarks`) and `tracking/video_tracker.py` (head camera solved the same way) still solve under a weak-perspective model; only their *output cameras* are converted to `PerspectiveCamera` (focal from `DEFAULT_FOCAL_FACTOR` or the real frame size), so the converted camera carries perspective foreshortening the fit itself never estimated. `io/glb_export.py` exports that tracker camera as weak-perspective; `identity_asset` honesty strings say so. A perspective rewrite of the bundle adjustment (unknown f, PnP per view) is a separate task.
2. **Crop-space compositor contract remains.** `Replacement` (crop + 2x3 inverse), `FrameCompositor` crop-to-frame I/O (`_crop_to_frame`, `warpAffine`/`fuse_crop`), `media/vfx.py`, `vfx_export.py`, `bridges/comfyui_bridge.py`, `pipeline/session_adapter.py` still move a rendered layer through an affine. With no producer it is unreachable, but it must become a frame-space RGBA + depth layer when the renderer is wired. Matting/occlusion/colour/temporal logic is reusable as is.
3. **Screen-space silhouette work kept (decision: delete only per-2D-triangle warpAffine).** `rendering/{silhouette_replacement,silhouette_inpaint,perimeter_cage}.py`, `swap_region_3d.py` and `HairDonorReplacer` (overhang inpaint + perimeter TPS cage on hair/ears/neck) are screen-space but not per-triangle warpAffine; a full-head render makes them unnecessary. They no longer run for a rendered layer (`projected=True` skips geometry planning).
4. `estimateAffinePartial2D` remains in `faceset/recognizer.py` (ArcFace 112 embedding input), `faceset_loader.py` (512 aligned crop for the FaceSet file) and `faceset_synthesizer.register_uv` (registers a LivePortrait portrait to mesh UV buffers). `aligned_crop` (ArcFace template only) stays for embedding / regressor inputs (`faceset_builder`, `morphable_backbone`, server face bank/extract). `reconstruction/neural_face._photograph_cache` still warps source photographs into an aligned cache (correspondence sampling).
5. **LivePortrait stays (decision), flagged**: `engine/volumetric/reference_adapter.py`, `expression_restorer.py`, `liveportrait_trt.py`, `faceset_synthesizer` view generation are 2D crop-based neural warps; `FaceSet` synthesis registers 36 generated 2D portraits. `ExpressionRestorer` is still invoked by the compositor when expression options are set.
6. **3DDFA-V3 / BFM-35709 backbone stays (decision)**: `morphable_backbone`, `native_backbone`, `native_face_geometry`, `neural_face.prepare` (face-region topology, no cranium; perspective camera). Only `neural_face.process` (the 2D swap feeder) was removed, so nothing renders from it.
7. `FullHeadEngine` is still not instantiated anywhere in the live path; `HeadRig` replaces the removed `IdentityRig` as its rig. Its jaw/eye/brow deformation weight fields use template x/y plane distances (face-plane Gaussians) and `FullHeadEngine.process` still hard-codes `focal = max(h, w) * 1.5` instead of calling `solve_dynamic_intrinsics`.
8. `rendering/hybrid_renderer.py` Gaussian splats have no trained weights; `RealESRGAN_x4plus` / `swin2_sr_x4` / `real_web_photo_x4` (frame upscalers) remain registered (not on the ban list). `evaluation/harness` profiles THREE_D_AWARE / LIVEPORTRAIT_ENHANCED are still simulated (sleep-based) baselines; `evaluation/reports` contains hard-coded sample numbers.
9. Not edited because not owned: tests, docs (`README`, `docs/*`, `ROOP3D_MASTER_TECHNICAL_AUDIT` etc. still describe the removed paths), `audit/*REPORT*`/`universal_model_manifest.json`/`verified_local_models.json`/`local_models_discovered.json` (derived inventories; regenerate with `tools/build_universal_manifest.py`), `app/roop_3d/outputs/**` scratch scripts that import deleted modules, the UI, `server/**`.
